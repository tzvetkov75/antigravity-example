# Security Checker Skill

When reviewing code, follow these steps:

## Review checklist

1. **Vulnarabilities**: Are there any security vulnarabilities?
2. **Vulnarabilities Fix**: Are there any fixes for the vulnarabilities?
3. **Context**: Are there any other clarifications needed for the context in order to provide security fixes?

## How to provide feedback

- Be specific about what needs to change
- Explain why, not just what
- Suggest alternatives when possible
