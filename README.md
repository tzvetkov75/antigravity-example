# Antigravity Example

A simple Python project demonstrating basic algorithms and unit testing.

## Features

- **Algorithms**:
  - `bubble_sort`: An in-place implementation of Bubble Sort.
  - `binary_search`: A standard implementation of Binary Search.
- **Unit Tests**: Comprehensive test coverage including distinct edge cases and error handling.

## Requirements

- Python 3.x
- Standard library only (no external dependencies)

## Usage

Run the main script to see examples of the algorithms in action:

```bash
python3 main.py
```

## Running Tests

Execute the unit tests using the standard `unittest` discovery:

```bash
python3 -m unittest discover -s . -p "test_*.py"
```
